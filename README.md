# Smart-Fruit-Grading-System
本作品搭建“鲜策智分”果蔬分级分拣系统，面向农产品加工、农贸及食堂采购，解决人工分选标准不一痛点。This "Smart Grader" on PYNQ‑Z2 realizes identification, grading, sorting and traceability. PL processes images; PS controls servos. Suspicious samples are rechecked by local vision model. Fast‑slow‑collaboration enables real‑time sorting. Configurable recipes support multi‑crop inspection.
